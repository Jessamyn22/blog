# 一、SSH服务的安全配置
## 1. 简介
SSH主要是在**不安全**的网络中加密管理服务器，默认使用TCP端口22，替代了早期Telnet、FTP等明文文件传输协议
## 2. 基于口令的SSH安全验证
1. 启用ssh服务 `systemctl start sshd`
2. 配置ssh服务主文件 `/etc/ssh/sshd_config`
	1. 编辑文件 `vim /etc/ssh/sshd_config` 
	2. 显示行号 `:set nu`
	3. 编辑38行 *PermitRottLogin* `38 PermitRootLogin no`
		- 拒绝root用户远程登录 只能普通用户登录，必须使用密码。 
3. 重启ssh服务 `systemctl restart sshd`
4. 选择另一台内网终端登录验证
	- `ssh <user>@<ip>`

## 3. 基于密钥的SSH安全验证
1. 启用ssh服务 `systemctl start sshd`
2. 配置ssh服务主文件 `/etc/ssh/sshd_config`
	1. 编辑文件 `vim /etc/ssh/sshd_config` 
	2. 显示行号 `:set nu`
	3. 新增公钥登录信息
		- 编辑38行 *PermitRottLogin* `38 PermitRootLogin no`、
		-  39行新增 `39 AllowUsers <user>`、
		-  44行新增 `44 PubkeyAuthentication yes` 允许使用公钥方式登录、
		- 48行新增 `48 AuthorizedKeysFile .ssh/authorized_keys` 公钥文件地址
	4. 重启SSH服务
	5. 新增用户，并对用户进行密钥对创建 
		- `useradd <uesr>` 新建用户
		- `passwd <user>` 修改密码
		- `su <user>` 切换用户
	6. 密钥创建
		- `ssh-keygen -t rsa`
		- `ssh-copy-id -i .ssh/id_rsa.pub <user>@<ip>` 复制密钥

# 二、Samba服务
## 1.简介
- Samba是实现SMB协议的一个免费软件，由服务器和客户端程序构成。
SMB是一种在局域网上共享文件和打印机的通信协议。
- 软件构成：samba、samba-common、samba-client
## 2. 配置文件
1. 全局共享参数
```text
[global]
workgroup = WORKGROUP
netbios name = MYSERVER
host allow = 127.192.168.12. 192.168.13.

```
