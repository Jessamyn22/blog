# 一、交换机的工作原理
## 0. 原理
拓扑图：
`PC1 ---- 交换机端口1      交换机端口2 ---- PC2`
### 第一步：学习源 MAC
交换机从端口1收到帧，看到源 MAC 是 `MAC-A`，于是记下来：
`MAC-A -> 端口1`
意思是：以后要找 PC1，就从端口1发。

### 第二步：查目的 MAC
交换机看到目的 MAC 是 `MAC-B`，去查 MAC 地址表。
如果表里已经有：
`MAC-B -> 端口2`
交换机就知道 PC2 接在端口2。

### 第三步：单播转发
交换机只从端口2把整个以太网帧原样发出去。它不会修改帧内容，也不会拆开看里面的 IP 包 A。
PC2 网卡收到帧后，发现目的 MAC 是 `MAC-B`，也就是自己，于是接收，去掉以太网头，把里面的 IP 包 A 交给操作系统上层处理。
所以这个过程是：
`PC1 -> 交换机端口1 -> 查表发现 PC2 在端口2 -> 交换机端口2 -> PC2`

## 2. VLAN 一般一个VLAN对应一个网段（VLAN通读，要通过路由）
