## 数据包列表含义
>eg.
>![[Pasted image 20261108210054.png|492]]

| 列名              | 含义               |
| --------------- | ---------------- |
| **No.**         | 包编号              |
| **Time**        | 抓取时距离开始的时间（s）    |
| **Source**      | 源 IP             |
| **Destination** | 目的 IP            |
| **Protocol**    | 协议名              |
| **Length**      | 包的字节数            |
| **Info**        | 摘要(这个牛逼啊，重点一般在这) |

## 数据包详情

```
Frame                             # 第 1 层：物理帧
└─ Ethernet II                    # 第 2 层：以太网
   ├─ Source / Destination MAC
   └─ EtherType                    # 0x0800 = IP, 0x0806 = ARP
   └─ Internet Protocol Version 4 # 第 3 层：IP
      ├─ Source / Destination IP
      ├─ TTL
      ├─ Protocol                  # 6=TCP, 17=UDP, 1=ICMP
      └─ ...
      └─ Transmission Control Protocol # 第 4 层：TCP
         ├─ Source / Destination Port
         ├─ Sequence Number
         ├─ Acknowledgment Number
         ├─ Flags                    # SYN/ACK/FIN/RST 等
         └─ ...
```
