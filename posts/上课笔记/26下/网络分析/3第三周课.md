# 捕获过滤器与显示过滤器

## 捕获过滤器（Capture Filter）
`捕获过滤器使用 libpcap / WinPcap 的语法，源自 BPF（Berkeley Packet Filter）。`
>ok其实上面一句废话，我也没懂什么玩意儿

特点
- 抓前生效，抓到的内容有针对性
- 语法简单，只能针对二三四层字段
- 写错了不会报错（语法合法就放行）

### 基本格式

```
<类型> <方向> <协议> <表达式>
```

| 关键字 | 含义 |
|---|---|
| `host` | 单个主机 IP |
| `net` | 一个网段 |
| `port` | 单个端口 |
| `portrange` | 端口范围 |
| `src` | 源 |
| `dst` | 目的 |
| `tcp`, `udp`, `icmp`, `arp`, `ip` | 协议限定 |
| `ether`, `ethernet` | 以太网限定 |
| `not`, `!` | 取反 |
| `and`, `&&` | 与 |
| `or`, `\|\|` | 或 |
>eg.

```text
 仅与 192.168.1.100 相关的所有流量
host 192.168.1.100

 仅 80 端口的 TCP 流量（即 HTTP）
tcp port 80

 源 IP 是 192.168.1.100，目的端口是 443 的 TCP
src host 192.168.1.100 and dst port 443

 192.168.1.0/24 网段的所有流量
net 192.168.1.0/24

 非 ARP 也非广播的所有流量
not arp and not broadcast

 仅 TCP SYN 包（建立连接的包）
tcp[tcpflags] & (tcp-syn) != 0

 仅 RST 包
tcp[tcpflags] & (tcp-rst) != 0
```

## 显示过滤器

显示过滤器使用 Wireshark **自有语法**，功能远超捕获过滤器。

**特点**：
- 抓包==后==生效，不影响 PCAP 文件
- 可以针对==任何==协议字段
- 表达式有语法检查，错的会变红
- 常用运算符：`==`、`!=`、`>`、`<`、`contains`、`matches` 等

>eg.

```text
 IP 过滤
ip.addr == 192.168.1.100
ip.src == 192.168.1.100
ip.dst == 192.168.1.1

 端口过滤
tcp.port == 80
udp.port == 53
tcp.srcport == 443

 协议过滤
http
dns
arp
icmp
tcp.analysis.retransmission   # TCP 重传

 字段内容过滤
http.request.method == "GET"
http.response.code == 200
http.host == "www.example.com"
dns.qry.name == "baidu.com"
tcp.flags.syn == 1
tcp.flags.reset == 1

 组合过滤
ip.addr == 192.168.1.100 and tcp.port == 80
http or dns
not arp and not stp
```

### 高级用法

- **contains**：模糊匹配（不区分大小写）。
  ```text
  http.host contains "example"
  ```
- **matches**：正则表达式。
  ```text
  http.request.uri matches "login|admin"
  ```
- **字段存在性判断**：
  ```text
  tcp.options.mss     # 任何包含 MSS 选项的 TCP 包
  ```

### 3. 捕获过滤器 vs 显示过滤器对比

| 对比项 | 捕获过滤器 | 显示过滤器 |
|---|---|---|
| 生效时机 | 抓包**前** | 抓包**后** |
| 语法 | libpcap / BPF | Wireshark 自有 |
| 性能影响 | **减少**磁盘写入 | 无性能影响 |
| 协议支持 | 仅二三四层 | 几乎所有协议 |
| 写法示例 | `tcp port 80` | `tcp.port == 80` |
| 错误处理 | 不报错 | 红色提示 |
