# TCP/IP 协议栈基础与抓包视角
## OSI 七层 vs TCP/IP 四层

| OSI 七层   | TCP/IP 四层 | 主要协议                 | 数据单元    |
| -------- | --------- | -------------------- | ------- |
| 7. 应用层   | 4. 应用层    | HTTP, DNS, FTP, SMTP | 报文      |
| 6. 表示层   | 4. 应用层    | TLS/SSL, MIME        | 报文      |
| 5. 会话层   | 4. 应用层    | NetBIOS, RPC         | 报文      |
| 4. 传输层   | 3. 传输层    | TCP, UDP             | 段 / 数据报 |
| 3. 网络层   | 2. 网络层    | IP, ICMP, ARP        | 包       |
| 2. 数据链路层 | 1. 网络接口层  | Ethernet, PPP, Wi-Fi | 帧       |
| 1. 物理层   | 1. 网络接口层  | 双绞线、光纤               | 比特      |
>`应表会传网链物`（OSI 七层自顶向下），或者 `网传应链`（TCP/IP 四层）。


## 数据封装
应用层数据（HTTP请求）
TCP头 - TCP段（Segment）
IP头 - IP包（Pakcet）
eth头 - 以太网帧（Frame）
前导码+FCS - 比特流（bits）

## 以太网头的关键字节

| 字段        | 长度  | 含义                                 |
| --------- | --- | ---------------------------------- |
| dest MAC  | 6字节 | 接收方的物理地址                           |
| src MAC   | 6字节 | 发送方的物理地址                           |
| EtherType | 2字节 | 0x0800=IPV4,0x0806=ARP,0x86DD=IPV6 |

## IP头关键字段

| 字段              | 长度    | 含义                       |
| --------------- | ----- | ------------------------ |
| Version         | 4bit  | 4=IPV4,6=IPV6            |
| IHL             | 4bit  | 头部长度（`*4`=字节数）           |
| Total Length    | 16bit | 整个IP包的长度                 |
| TTL             | 8bit  | 生存时间，每过一条`-1`，到`0`就丢包    |
| Protocol        | 8bit  | 6=TCP,17=UDP,1=ICMP  协议号 |
| Source IP       | 32bit | 源IP                      |
| destination IP  | 32bit | 目的IP                     |
| Header Checksum | 16bit | 头部校验和                    |
## TCP头
| 字段                    | 长度    | 含义                      |
| --------------------- | ----- | ----------------------- |
| Source Port           | 16bit | 源端口                     |
| destination Port      | 16bit | 目的端口                    |
| Sequence Number       | 32bit | 序列号                     |
| Acknowledgment Number | 32bit | 确认号                     |
| Flags                 | 12bit | SYN/ACK/FIN/RST/UGR/PSH |
| window Size           | 16bit | 接收窗口                    |
| Checksum              | 16bit | 校验和                     |
## UDP数据报头
| 字段               | 长度    | 含义           |
| ---------------- | ----- | ------------ |
| Source Port      | 16bit | 源端口          |
| destination Port | 16bit | 目的端口         |
| Length           | 16bit | UDP头（8）+数据总长 |
| Checksum         | 16bit | 校验和（可选）      |
