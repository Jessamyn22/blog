# 数据的打开、保存与导出
## pcap 与 pcapng 的区别

| 格式         | 扩展名       | 特点                         |
| ---------- | --------- | -------------------------- |
| **pcap**   | `.pcap`   | 经典格式，所有抓包工具都支持             |
| **pcapng** | `.pcapng` | 新格式，支持多接口、注释、加密，比 pcap 更现代 |

## 保存
### 三种保存方式

`File → Save As...`

- 默认保存为 `.pcapng`。
- 可以选择保存为 `.pcap`。
- 文件大小 = 全部包的字节总数 + 头部开销。

### 保存过滤后的包

`File → Export Specified Packets...`

- 弹出窗口，可以选：
  - "All packets"
  - "Selected packet only"
  - "Range"（包编号范围）
  - "Marked packets only"（打过标记的）

### 仅保存显示过滤后的"包列表可见"内容

`File → Save As...`

- 如果保存前**应用了显示过滤器**，保存时可以选择"All packets"或"All displayed"。
- "All displayed" = 只保存当前列表里可见的包。

### 导出特定分组（按包号）

`File → Export Specified Packets... → Range`

- 例如输入 `1-10` 或 `15,17,20`，只导出指定编号的包。
- 适合做报告时只截取"关键证据"。



## 包的大小
### 自动分卷（Multiple Files）

`Capture → Options → Output → Create a new file...`

- **按大小切分**：每 N MB 自动生成新文件。
- **按时间切分**：每 N 秒自动生成新文件。

### 环形缓冲区（Ring Buffer）

`Capture → Options → Output → Use a ring buffer`

- 设置保留文件数 N，达到 N 个文件后，**覆盖最老的**。
- 长期抓包必备：硬盘永远不会爆。

### 设置保存路径

`Capture → Options → Output → File`

- 强烈建议**不要**保存在 C 盘（Windows）或系统盘。
- 推荐建专门的目录，例如 `D:\captures\`。

### 配置文件的导入与导出

Wireshark 的所有个性化设置（过滤器、颜色规则、列定义）都存在配置文件夹。

| 系统 | 路径 |
|---|---|
| Windows | `%APPDATA%\Wireshark\profiles\` |
| Linux | `~/.config/wireshark/profiles/` |
| macOS | `~/.config/wireshark/profiles/` |
