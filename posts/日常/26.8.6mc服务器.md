````bash
java -jar forge-installer.jar --installServer
````

# EULA
````bash

# 把内存参数写进 user_jvm_args.txt
echo "-Xms2G -Xmx4G" >> user_jvm_args.txt

# 首次启动，等它生成 eula.txt 后自动退出
bash run.sh

# 同意协议
sed -i 's/eula=false/eula=true/' eula.txt

# 再次启动，看到 Done 即成功
bash run.sh
````

# system服务
我直接配置了systemctl服务为了方便（有点麻烦就不写了）

| 操作     | 命令                                         |
| ------ | ------------------------------------------ |
| 查看实时日志 | journalctl -u minecraft -f                 |
| 重启服务器  | systemctl restart minecraft                |
| 停止服务器  | systemctl stop minecraft                   |
| 编辑配置   | vim ./server.properties                    |
| 加白名单   | vim whitelist.json 游戏内 /whitelist add 玩家ID |

然后是关于服务器的实时命令配置，我这边使用的是==**RCON**==
1. 在 server.properties 里加上：
```ini
enable-rcon=true
rcon.port=25575
rcon.password=<Password>
```
2. 进入==**RCON**==
```bash
mcrcon -H <host> -P 25575 -p <password>
```
3. 一些基本的命令（省的哪天我忘记）

| 命令 | 作用 | 示例 |
|------|------|------|
| `op 玩家名` | 给玩家管理员权限 | `op Steve` |
| `deop 玩家名` | 取消管理员 | `deop Steve` |
| `whitelist add 玩家名` | 添加白名单 | `whitelist add Alex` |
| `whitelist remove 玩家名` | 移除白名单 | `whitelist remove Alex` |
| `whitelist reload` | 重载白名单生效 | — |
| `whitelist list` | 查看白名单列表 | — |
| `ban 玩家名` | 封禁玩家 | `ban Griefer` |
| `pardon 玩家名` | 解封玩家 | `pardon Griefer` |
| `kick 玩家名` | 踢出玩家 | `kick AFKbot` |
| `list` | 查看在线玩家 | — |
| `say 消息` | 公屏广播 | `say 欢迎新玩家` |
| `tell 玩家名 消息` | 私聊某玩家 | `tell Steve 来我家` |
| `time set day` | 设为白天 | — |
| `time set night` | 设为黑夜 | — |
| `time set noon` | 设为正午 | — |
| `weather clear` | 晴天 | — |
| `weather rain` | 雨天 | — |
| `weather thunder` | 雷暴 | — |
| `gamemode creative 玩家` | 切创造模式 | `gamemode creative Steve` |
| `gamemode survival 玩家` | 切生存模式 | `gamemode survival @a` |
| `give 玩家 物品 数量` | 给予物品 | `give Steve diamond 64` |
| `tp 玩家 目标` | 传送玩家 | `tp Steve Alex` |
| `kill 玩家` | 杀死玩家 | `kill @e[type=creeper]` |
| `difficulty peaceful` | 切和平难度 | — |
| `difficulty hard` | 切困难难度 | — |
| `save-all` | 手动保存存档 | — |
| `stop` | 关闭服务器 | — |

`@a` = 所有玩家，`@e` = 所有实体。
